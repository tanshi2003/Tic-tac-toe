# Tic Tac Toe

A browser-based Tic Tac Toe game where you can challenge a computer opponent or play locally with a friend. Choose a bot difficulty, keep track of wins and draws, and restart rounds without losing your match score.

## Features

- Single-player mode against an AI bot with Easy, Smart, and Unbeatable difficulty levels.
- Local two-player mode for friendly head-to-head matches.
- Automatic win and draw detection with highlighted winning cells.
- Scoreboard for Player X, Player O, and draws.
- Scores saved in the browser using local storage.
- Restart the current round, start a fresh match, or reset scores independently.
- Responsive layout for desktop and mobile.

## Play online

https://tanshi2003.github.io/Tic-tac-toe/

## Run locally

No build tools or dependencies are required. Clone the repository and open `index.html` in a browser.

## Built with

HTML, CSS, and JavaScript.
